The candidate now packages every tracked portable-core/companion file, original
split LICENSE and source-scope document in an exact Git-pinned source ZIP. Native
scenario/answer/CLI and other content trees are excluded. External RALLY stays at
the prior exact revision; the package is buildable corresponding source rather
than an offline vendor pack or full repository archive. Browser dependency/Rust
notices, build/provenance/source/artifact links and separate size budgets are
independent of engine startup. No claim of ownership over third-party content.

inventory, Git blobs and the known native answer-word boundary, including ZIP
contents. Foundation protection retains twelve native functions, four extracted
formulas, variant constants, policy/grants and the original README prefix. Only a
scoped front-door append changes that document. Native algorithm/RNG/defaults,

Recovery coverage adds actual read/startup/compute deadlines, stale reads/edits/
IDs/generations, malformed responses, worker termination/crash/restart, whole-input/
file/drop/paste admission and maximum input plus actual WASM memory ceiling.

Synthetic lifecycle faults are not forecast outcomes or golden controls.

native and four adapter tests, all 48 original native CLI hashes repeated twice
without publishing raw scenario output, 46 native/WASM controls, full artifact/source
custody, and independent source replay outside Git in a path with spaces. Replay
must reproduce 46 native and 46 WASM outcomes separately plus twelve behavior
cases. This candidate has not passed those final gates merely by implementing
the helpers or by preserving the earlier eleven-case result.

deployment uses only the tested artifact and re-verifies its transfer. A fresh
live file/hash/browser/outcome check is required before a separate TRACKER pulse.
